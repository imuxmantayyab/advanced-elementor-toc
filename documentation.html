Advanced Table of Contents for Elementor

A high-performance, accessible, and deeply customizable Table of Contents Elementor Widget engineered with pure vanilla JavaScript, IntersectionObserver scroll spy, live search, and multiple responsive display formats.

⚡ 0% jQuery Dependency
📱 Mobile Drawer & Sticky Bar
♿ WCAG & RTL Ready
🎨 8 Visual Presets

1. System Requirements

Ensure your environment satisfies the minimum requirements before installation:

🐘

PHP Environment

PHP 7.4 or higher (PHP 8.0, 8.1, 8.2, 8.3 fully supported with zero notices).

🌐

WordPress

WordPress 5.8 or higher (tested up to latest WordPress core releases).

📐

Elementor

Elementor Free 3.5.0+ or Elementor Pro 3.5.0+.

2. Installation & Setup

  1. Upload Plugin Archive

    In your WordPress Dashboard, go to Plugins → Add New → Upload Plugin. Choose advanced-elementor-toc.zip and click Install Now.

  2. Activate the Plugin

    Click Activate Plugin after upload. The plugin will register the new Advanced Elements category in Elementor.

  3. Configure Global Defaults (Optional)

    Visit Settings → Advanced TOC to configure default heading levels, transient caching duration, and conditional asset loading.

3. Quick Start Guide

Adding the Table of Contents widget to any page or theme template takes under 30 seconds:

💡

Pro-Tip: You can place the widget inside single post templates created with Elementor Theme Builder. The TOC will automatically detect headings from whichever post is rendered!

  1. Open Elementor Editor

    Edit any Post, Page, or Theme Builder Template.

  2. Drag the Widget

    Search for Advanced Table of Contents and drag it into your desired sidebar or content section.

  3. Select Heading Levels

    Under the Content tab, select which headings to include (e.g. H2, H3, H4).

4. Elementor Widget Content Controls

Control Name Options / Range Description
Include Headings H1, H2, H3, H4, H5, H6 Select any combination of heading tags to parse.
Heading Source Entire Page, Post Content, Elementor Content, Custom CSS Selector Choose where to scan for candidate headings.
Exclude by Text Textarea (comma / line separated) Exclude headings matching exact words (e.g. "Conclusion", "Comments").
Exclude by Class/Selector Text inputs Skip headings with classes like .no-toc or selectors like .sidebar h2.
Numbering Style None, Numeric, Hierarchical, Alphabetical, Roman, Custom Prefix Format heading numbers (e.g., 1.1.2, Section A).
Max Depth & Visible Items H2–H6 depth, 0 to 100 items Limit TOC length and provide an expandable "View More" button.
Collapsible Box Switcher (Yes/No), Animation ms Allows visitors to toggle the TOC card open and closed.
Sticky & Floating Mode Top, Bottom, Corner Floating Card Pin navigation to screen with custom clearance offsets.

AdvancedElementorTOC.destroy();

8. Frequently Asked Questions

Q: Why does the widget say "No headings found"?

Ensure your page has headings matching the tags selected in Include Headings (e.g. H2, H3). If your headings are in a custom layout, set Heading Source to Entire Page or specify your Custom CSS Selector.

Q: How do I adjust clearance for fixed header menus?

Go to Advanced → Scroll Offset (Header Clearance px) in the widget and set it to your header's pixel height (e.g. 110px).

Q: Does this plugin support RTL languages?

Yes. The entire stylesheet is built with CSS logical properties (margin-inline-start, etc.) for native Arabic, Hebrew, and Urdu layout support.
