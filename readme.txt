== Description ==

**Advanced Table of Contents for Elementor** is a standalone, performance-focused WordPress plugin that provides an advanced, responsive, and SEO-friendly Table of Contents widget for Elementor Free and Pro.

### Key Features:
* **Dynamic Heading Detection**: Automatically detects headings (H1–H6) across the entire page, post content, Elementor sections, or custom CSS selectors.
* **Heading Exclusion & Filtering**: Filter headings by text, CSS classes, CSS selectors, or skip the first/last N headings.
* **Smart Hierarchy & Numbering**: Nested tree navigation with Roman, Alphabetical, Numeric, Hierarchical (1.1, 1.2), or Custom Prefix numbering.
* **IntersectionObserver Scroll Spy**: High-performance active heading tracking with zero scroll lag.
* **Smooth Scrolling with Header Clearance**: Custom pixel offsets to prevent fixed navigation bars from covering headings.
* **Live In-TOC Search**: Fast, client-side real-time filter for large articles and documentations.
* **Reading Progress Bar**: Horizontal bars, circular percentages, or text displays that track reading progress.
* **8 Beautiful Design Presets**: Modern, Classic, Minimal, Sidebar, Floating Card, Compact, Documentation, and Glassmorphism.
* **Mobile Experience Modes**: Accordion, Dropdown, Slide-up Bottom Drawer, or Floating Action Bar.
* **SEO Optimized**: Generates clean, unique anchor slugs without duplicate IDs, preserving manual IDs.
* **WCAG Accessible & RTL Ready**: Semantic `<nav>`, ARIA tags, keyboard navigation, and logical CSS properties (`margin-inline-start`, etc.).
* **Vanilla JavaScript Engine**: 0% jQuery dependency for maximum loading speed.

== Installation ==

1. Upload the `advanced-elementor-toc.zip` file via **Plugins -> Add New -> Upload Plugin** in your WordPress admin.
2. Click **Install Now** and then **Activate**.
3. Open any post or page in Elementor.
4. Drag and drop the **Advanced Table of Contents** widget from the **Advanced Elements** category.
5. Customize heading levels, styling presets, animations, and sticky options to your liking!

== Frequently Asked Questions ==

= Does this require Elementor Pro? =
No! The widget is 100% compatible with both Elementor Free and Elementor Pro.

= Does it support RTL languages like Arabic or Hebrew? =
Yes! The styles use modern CSS logical properties (`margin-inline-start`, `padding-inline-start`), providing native support for right-to-left languages without extra configuration.

= Can I use it on WooCommerce single product pages or custom post types? =
Yes. It dynamically scans the rendered DOM of any post, page, product, or custom post type template.
